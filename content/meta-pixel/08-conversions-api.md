إلى جانب البكسل توفر Meta مساراً ثانياً لاستقبال الأحداث اسمه **Conversions API**. ستصادف اسمه في إعدادات إضافات التتبع ومنصات المتاجر، فمن المفيد أن تعرف ما هو وأين تجد ما يلزم لربطه.

## ما هو

Conversions API يُستخدم عندما نريد اتصالاً **Server-to-server** (من خادم إلى خادم): خادم متجرك يرسل الحدث مباشرة إلى خوادم Meta.

| | Meta Pixel | Conversions API |
|---|---|---|
| من يرسل الحدث | الكود المحمَّل في صفحة المتجر عند الزائر | خادم المتجر |
| ما يلزم للربط | Pixel ID | Pixel ID ورمز وصول |
| أين يُضبط | في الموقع، أو إضافة، أو Google Tag Manager | في إعدادات المنصة أو الإضافة أو أداة ربط تدعمه |

المساران يخدمان الغرض نفسه: إيصال أحداث متجرك إلى Meta. والأحداث الواصلة عبر أي منهما تُسجَّل على البكسل نفسه، أي على مجموعة البيانات نفسها.

## توليد رمز الوصول

الربط يحتاج **Access token** (رمز وصول) تولّده من Events Manager:

1. افتح **Events Manager** (مدير الأحداث).
2. افتح **Datasets** (مجموعات البيانات) واختر البكسل.
3. انتقل إلى تبويب **Settings** (الإعدادات).
4. في قسم Conversions API اضغط **Generate access token** (توليد رمز وصول).
5. انسخ الرمز واحفظه في مكان آمن.

> **تنبيه:** رمز الوصول بمثابة كلمة مرور لبيانات البكسل. لا تشاركه في محادثة أو بريد، ولا تضعه إلا في الحقل المخصص له داخل الأداة التي تثق بها.

## أين تستخدم الرمز

في الأداة التي تتولى الإرسال من جهة الخادم. الأماكن المعتادة:

- إعدادات إضافة التتبع في متجرك، حيث تجد حقلاً لرمز Conversions API بجانب حقل Pixel ID.
- إعدادات الربط مع Meta في منصة متجرك، إن كانت توفر ذلك.

تلصق الرمز مع Pixel ID وتحفظ.

## هل تحتاجه الآن؟

- البكسل وحده يكفي لبدء التتبع وتشغيل الحملات واختبار الأحداث.
- Conversions API مسار إضافي. إن كانت منصة متجرك أو إضافتك توفره بحقل جاهز، فتفعيله لا يتطلب أكثر من توليد الرمز ولصقه.
- إن لم يكن متاحاً بحقل جاهز، فإعداده عمل تقني، والأفضل أن يتولاه مطوّر.

## الاختبار بعد التفعيل

استخدم تبويب **Test events** (اختبار الأحداث) كما تفعل مع البكسل:

1. افتح متجرك من التبويب وتصفحه.
2. نفّذ الإجراء الذي تتتبعه، مثل طلب تجريبي.
3. تأكد أن الحدث يظهر، وأنه لا يُحتسب مرتين.

> **خطأ شائع:** تفعيل Conversions API مع بقاء البكسل، ثم رؤية كل حدث مرتين في التقارير دون الانتباه. بعد التفعيل راجع الأحداث في Events Manager، وتأكد من أن أداتك تمنع الاحتساب المزدوج للحدث الواحد.

## ترتيب الأولويات

1. أنشئ البكسل وثبّته.
2. اختبر الأحداث الأساسية وتأكد أنها تصل.
3. شغّل حملاتك.
4. بعدها فعّل Conversions API إن كان متاحاً بسهولة في منصتك.

لا تؤخر البدء بانتظار إعداد كل شيء. تتبع يعمل عبر البكسل اليوم خير من إعداد كامل مؤجل.

## الخلاصة

- Conversions API مسار لإرسال الأحداث من خادم متجرك إلى خوادم Meta مباشرة.
- يحتاج Pixel ID ورمز وصول.
- الرمز يُولَّد من Events Manager: Datasets، ثم Settings، ثم Generate access token.
- احفظ الرمز كما تحفظ كلمة المرور.
- البكسل يكفي للبدء، و Conversions API إضافة تفعّلها حين تتوفر بسهولة.
- اختبر بعد التفعيل وتأكد من عدم تكرار الأحداث.
