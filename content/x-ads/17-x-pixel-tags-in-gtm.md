بعد أن نسخت **Pixel ID** و**Event ID** من مدير الأحداث في X، ووضعت كود Google Tag Manager في متجرك، يبقى إنشاء ثلاثة عناصر داخل GTM: مشغّل لحدث الشراء، ووسم للبكسل الأساسي، ووسم لحدث الشراء. هذا الموضوع يشرحها بالترتيب.

## ما ستنشئه

| العنصر | النوع | وظيفته |
|---|---|---|
| مشغّل الشراء | Trigger | يحدد لحظة وقوع الشراء في المتجر |
| X Base | Tag | يعمل على كل صفحة ويخبر X بوجود زيارة |
| X Purchase | Tag | يعمل عند الشراء فقط ويخبر X بعملية البيع |

## ما تحتاجه قبل البدء

- حاوية GTM مثبتة على المتجر.
- **Pixel ID** من خيار Tag manager في مدير الأحداث.
- **Event ID** لحدث الشراء من إعداد Purchase tracker.
- أن يرسل متجرك حدث شراء يمكن لـ GTM التقاطه (انظر التنبيه في الخطوة الأولى).

## الخطوة الأولى: مشغّل حدث الشراء

1. في GTM افتح **Triggers** (المشغّلات) واضغط **New** (جديد).
2. اضغط **Trigger Configuration** (إعداد المشغّل).
3. اختر النوع **Custom Event** (حدث مخصص).
4. في اسم الحدث اكتب **purchase**.
5. سمِّ المشغّل باسم واضح واحفظ.

معنى هذا المشغّل: أينما ورد حدث باسم purchase في الموقع يُعدّ عملية شراء.

> **تنبيه:** المشغّل يعمل فقط إذا كان متجرك يرسل فعلاً حدثاً بهذا الاسم عند إتمام الطلب. هذه الأحداث تُعرَّف مسبقاً داخل الموقع نفسه. تأكد من اسم الحدث الذي يرسله متجرك عبر وضع المعاينة في GTM، واكتبه كما يظهر تماماً.

بالطريقة نفسها يمكنك إنشاء مشغّلات لأحداث أخرى، مثل بدء الدفع.

## الخطوة الثانية: العثور على قالب X الصحيح

1. افتح **Tags** (الوسوم) واضغط **New** ثم **Tag Configuration** (إعداد الوسم).
2. ابحث عن **Twitter**.
3. سيظهر وسم قديم موسوم بـ Legacy. لا تستخدمه؛ أصبح قديماً.
4. افتح **Community Template Gallery** (معرض قوالب المجتمع) وابحث عن **Twitter**.
5. ستجد قالبين:

| القالب | وظيفته | ما يطلبه |
|---|---|---|
| **Twitter Base Pixel** (البكسل الأساسي) | يُطلق على كل صفحة، ويرسل إلى X إشارة بوجود زيارة للموقع | Pixel ID |
| **Twitter Event Pixel** (بكسل الأحداث) | لحدث محدد مثل الشراء | Event ID |

> **نصيحة:** ابحث بكلمة «Twitter» لا «X». القوالب ما زالت مسماة بالاسم القديم للمنصة، والبحث بالاسم الجديد قد لا يعطي نتيجة واضحة.

## الخطوة الثالثة: وسم البكسل الأساسي

1. اختر قالب **Twitter Base Pixel** وأضفه إلى مساحة العمل إن طُلب منك ذلك.
2. الصق **Pixel ID** في الحقل المخصص.
3. في قسم Triggering اختر المشغّل **All Pages** (كل الصفحات).
4. سمِّ الوسم **X Base**.
5. اضغط **Save** (حفظ).

هذا الوسم هو الأساس: به تعرف X أن موقعك موجود وأن زواراً يدخلونه، وعليه تُبنى جماهير زوار الموقع.

## الخطوة الرابعة: وسم حدث الشراء

1. أنشئ وسماً جديداً واختر قالب **Twitter Event Pixel**.
2. اضغط **Add to workspace** (إضافة إلى مساحة العمل).
3. الصق **Event ID** الخاص بحدث الشراء في الحقل المطلوب.
4. في قسم Triggering اختر مشغّل الشراء الذي أنشأته في الخطوة الأولى.
5. سمِّ الوسم **X Purchase**.
6. احفظ.

> **خطأ شائع:** ربط وسم الشراء بالمشغّل All Pages. حينها تُسجَّل عملية شراء مع كل زيارة صفحة، فتتضخم أرقام المبيعات وتتعلم المنصة من بيانات خاطئة. وسم الشراء يُربط بمشغّل الشراء فقط.

### معاملات إضافية

قالب بكسل الأحداث يتيح تمرير بيانات إضافية مع الحدث:

| المعامل | ما يحمله |
|---|---|
| **Value** | قيمة الطلب |
| **Currency** | العملة |
| **Conversion ID** | معرّف التحويل |
| **Description** | وصف |
| **Content name** | اسم المحتوى |

إن كان متجرك يوفر هذه القيم فمرّرها لتظهر قيمة المبيعات في تقاريرك. وإن لم تكن متاحة فاكتفِ بمعرّف الحدث؛ المطلوب الأساسي شيئان فقط: Pixel ID وEvent ID.

## ملخص الإعداد

| الوسم | القالب | المعرّف | المشغّل |
|---|---|---|---|
| X Base | Twitter Base Pixel | Pixel ID | All Pages |
| X Purchase | Twitter Event Pixel | Event ID لحدث الشراء | Custom Event باسم purchase |

## إضافة أحداث أخرى

إذا أردت تتبع حدث آخر، مثل العميل المحتمل أو التنزيل، فكرر الخطوات نفسها:

1. انسخ Event ID للحدث من مدير الأحداث في X.
2. أنشئ مشغّلاً من نوع Custom Event باسم الحدث الذي يرسله متجرك.
3. أنشئ وسماً جديداً بقالب Twitter Event Pixel والصق المعرّف.
4. اربط الوسم بمشغّله وسمِّه باسم واضح، مثل «X Lead».

## قبل النشر: اختبر

لا تنشر التغييرات قبل اختبارها. اضغط **Preview** (معاينة) في GTM وتحقق أن كل وسم يُطلق في لحظته الصحيحة. تفاصيل الاختبار وتفعيل الأحداث في الموضوع التالي.

## الخلاصة

- تنشئ في GTM مشغّلاً من نوع Custom Event لحدث الشراء، ووسمين: الأساسي ووسم الشراء.
- ابحث عن القوالب باسم Twitter في معرض قوالب المجتمع، وتجنب الوسم القديم Legacy.
- وسم X Base يستخدم Pixel ID ويعمل على All Pages.
- وسم X Purchase يستخدم Event ID ويُربط بمشغّل الشراء فقط.
- يمكن تمرير القيمة والعملة وبيانات أخرى إن كان متجرك يوفرها.
- اختبر عبر Preview قبل النشر.
